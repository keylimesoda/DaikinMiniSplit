Projects included for Windows (WinUI3), Android (UNO), and PowerShell

This is a project to play around with the local Daikin API.  Only works on older Daikins.

The app will survey the local network to find the Daikin unit.  It will then survey the unit to see what APIs are exposed by the device.

In app usage, you can set temp and function type, set/adjust basic schedule, and look at the diagnostics (including raw API responses).

Scheduling is still buggy.  But other stuff seems to be working well on my unit.
